1. Tài Khoản Facebook (Outreach)

Cấu hình Profile Chrome hoặc Cookie để bot mở trình duyệt tìm group và gửi câu hỏi duyệt nhóm.

Khuyên dùng: Dùng profile Chrome đã đăng nhập sẵn nick của bạn để không cần gõ mật khẩu
🛒

2. Shopee Affiliate & Cookie

Cần có ít nhất 1 trong 2: Cookie Shopee hoặc Shopee Open API để tránh bị sàn chặn 403.

F12 trên affiliate.shopee.vn $\rightarrow$ Network $\rightarrow$ Copy Header 'Cookie' dán vào đây
F12 trên shopee.vn $\rightarrow$ Network $\rightarrow$ Copy Header 'Cookie' dán vào đây
🛍️

2b. Lazada Affiliate & Open Platform API

Cấu hình App Key/Secret từ open.lazada.com hoặc Cookie/Tracking URL từ Lazada Affiliate Portal.

Lấy tại open.lazada.com nếu bạn dùng Open Platform API chính thức
F12 trên affiliate.lazada.vn $\rightarrow$ Network $\rightarrow$ Copy Header 'Cookie'
Đường link tracking mẫu do Lazada cấp trong phần Ads Link Generator
✈️

3. Kênh Nhà (Telegram Bot)

Bắn deal hot tự động vào Kênh/Group Telegram của bạn ngay khi vừa săn được.

Tạo miễn phí qua bot @BotFather trên Telegram
🛡️

4. Tiêu Chuẩn Lọc & Hạn Mức An Toàn

Điều chỉnh các ngưỡng thuật toán để chọn ra sản phẩm chất lượng nhất.

Khuyên dùng: 3 group/ngày để bảo vệ tài khoản
🚀

5. Kênh Cộng Đồng Riêng (PR Kéo Member)

Tự động chèn link mời vào nhóm Zalo/Telegram/FB của bạn vào cuối các bài viết tổng hợp deal và lịch sale.

Hệ thống sẽ dùng link này để kéo người dùng từ các group khác về cộng đồng của bạn
🔗

6. Chế Độ Link Chuyển Hướng (Anti-Die Link)

Cấu hình cách hoạt động của link khi chia sẻ lên Facebook để đảm bảo 100% không bị chết khi tắt máy tính.

* Ở chế độ "Trực tiếp", link sẽ dẫn thẳng tới sàn qua tracking Sub-ID, máy bạn tắt người dùng vẫn bấm mua bình thường!
🔒

7. Bảo Mật API & Quản Trị Hệ Thống

Thiết lập Secret Admin Key để bảo vệ các API nhạy cảm khi deploy ra môi trường Internet công khai.

Khi thiết lập, các tác vụ kích hoạt chạy (/api/run), sửa cấu hình (/api/config) sẽ yêu cầu header X-Admin-Key
